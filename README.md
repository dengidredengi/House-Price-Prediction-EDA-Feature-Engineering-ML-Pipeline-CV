# House-Price-Prediction-EDA-Feature-Engineering-ML-Pipeline-CV

Проект содержит прогнозирование цен на жильё в Южной Калифорнии (SoCal) на основе табличных данных и фотографий домов.

## Датасет

[House Prices and Images — SoCal (Kaggle)](https://www.kaggle.com/datasets/ted8080/house-prices-and-images-socal/data)

**Признаки:**

| Признак | Описание |
|---|---|
| `image_id` | ссылка на фото дома в папке `houses_pics` |
| `street` | адрес (улица) |
| `city` | город (категориальный) |
| `encoded_city` | город, закодированный числом (LabelEncoder) |
| `bed` | количество спален |
| `bath` | количество ванных комнат |
| `sqft` | площадь дома (кв. футы) |
| `price` | цена дома (целевая переменная) |

## Pipeline

**1. Импорт и очистка данных:** Загрузка, переименование колонок, приведение типов, проверка пропусков и дубликатов.

**2. Feature Engineering + EDA:** Создание новых признаков (`price_per_sqft`, `rooms`, `avg_room_square`), логарифмирование скошенных признаков (`price`, `sqft`), анализ распределений, корреляций и зависимостей (цена от локации, площади, числа комнат).

**3. Подготовка данных к обучению:** Отбор признаков, логарифмирование целевой переменной, разделение на train/test.

**4.1 Baseline:** Решающее дерево (`DecisionTreeRegressor`) как опорная модель.

**4.2 Оптимизация модели:** Случайный лес (`RandomForestRegressor`) с подбором гиперпараметров через `GridSearchCV` и 5-fold кросс-валидацию.

**5. Computer Vision:** Извлечение визуальных представлений фотографий домов с помощью предобученной свёрточной сети `ResNet18`. Эмбеддинги склеиваются с табличными признаками по `image_id`, сжимаются через PCA и подаются в случайный лес. Цель: проверить, улучшает ли картинка дома предсказание цены.

## Ключевые наблюдения

- **Локация — сильнейший фактор цены:** разрыв между дорогими прибрежными районами и дешёвыми пустынными городами достигает 7–8 раз.
- **Цена за квадрат обратно связана с размером** дома: большие дома дешевле в пересчёте на квадратный фут.
- **Мультиколлинеарность** среди `bed`, `bath`, `rooms` - фактически один признак «размер дома».
- **Нелинейные зависимости** в данных - линейные модели плохо подходят, поэтому выбраны деревья и ансамбли.

## Результаты основного пайплайна

Предсказывается логарифм цены (`log_price`), метрики на тестовой выборке:

| Модель | MSE | MAE | R² |
|---|---|---|---|
| Решающее дерево (baseline) | 0.135 | 0.218 | 0.483 |
| **Random Forest (оптимизированный)** | **0.085** | **0.201** | **0.673** |

Случайный лес объясняет **67% вариации цены** против 48% у одиночного дерева - прирост R² почти в 1.5 раза за счёт ансамблирования и подбора гиперпараметров.

### Результаты CV

| Модель | R² | MSE |
|---|---|---|
| Random Forest (оптимизированный) | 0.673 | 0.085 |
| Random Forest + 512 эмбеддингов ResNet | 0.520 | 0.125 |
| Random Forest + 30 PCA-компонент | 0.548 | 0.118 |

Добавление фотографий не улучшило модель. Цену определяют метраж и локация, которые уже присутствуют в табличных данных, а одна фотография фасада не несёт дополнительного ценового сигнала и лишь вносит шум в ансамбль. Лучшая модель - случайный лес на табличных признаках (R² = 0.673).
